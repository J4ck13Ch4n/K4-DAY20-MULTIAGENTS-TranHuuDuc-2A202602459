---
name: validate-changelog
description: Use this skill to ensure that all changes are properly documented in the CHANGELOG.md file.
---
- Open the CHANGELOG.md file.
- Check for the heading '## Unreleased'.
- Ensure that each fix is documented as a bullet point in the format '- fix(<function name>): <short description>'.
- Verify that at least three bullet points are present for recent changes.
- If any entries are missing, add them according to the specified format.
- Review the changelog for clarity and completeness before finalizing.
