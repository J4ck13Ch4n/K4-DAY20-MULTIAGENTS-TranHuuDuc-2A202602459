---
name: check-type-annotations
description: Use this skill to ensure all public functions have type annotations for parameters and return values.
---
- Review all public functions in the codebase.
- For each function, check if all parameters have type annotations.
- Ensure the return type of the function is also annotated.
- If any annotations are missing, add appropriate type hints.
- Run a linter or type checker to verify that all functions comply with the type annotation rules.
- Document any changes made to the code for future reference.
